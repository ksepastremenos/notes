Συντομεύσεις για Windows. Σε Mac, όπου λέει Ctrl πατάμε Cmd.

| Συντόμευση | Τι κάνει |
|---|---|
| Ctrl+Z | Αναίρεση (undo) |
| Ctrl+Shift+Z | Επανάληψη (redo) |
| Ctrl+S | Αποθήκευση |
| A | Εργαλείο επιλογής |
| B | Λεπίδα (blade): κόβουμε clips με κλικ |
| Ctrl+B | Κόψιμο στη θέση του playhead |
| Ctrl + / Ctrl − | Zoom μέσα / έξω στο timeline |
| Shift+Z | Όλο το timeline χωράει στην οθόνη |
| Backspace | Διαγραφή (αφήνει κενό) |
| Delete | Ripple delete |
| D | Απενεργοποίηση / ενεργοποίηση clip |
| Shift+F | Εικόνα σε πλήρη οθόνη |
| Ctrl+F | Cinema Viewer (Esc για έξοδο) |

#### Ripple delete

Σβήνει το clip **και κλείνει το κενό**: ό,τι ακολουθεί μετακινείται πίσω, ώστε να μη μείνει τρύπα στο timeline. Η απλή διαγραφή (Backspace) αφήνει το κενό.

Όλες οι συντομεύσεις φαίνονται και αλλάζουν στο DaVinci Resolve › **Keyboard Customization** (Ctrl+Alt+K).
